# Offline OpenAPI 3.1 structural lint

The source file `openapi-3.1-2026-08-03.schema.json` is the OpenAPI Initiative's published [OpenAPI 3.1 structural schema](https://spec.openapis.org/oas/3.1/schema/2026-08-03). Its SHA-256 is `59f106413cb48c31299f96f024c938d3628aed6cd02cd14bcfb2fcaae7a130b6`. It is retained byte-for-byte for provenance.

`auth-user-friend.openapi.validator.js` is an offline standalone validator generated by `build-openapi-3.1-validator.js` with Ajv `8.20.0`; its SHA-256 is `682b5f51c053c9876c16a6bdd92fb8968a50c6df1d4bab44d6e8e184ce9c7ee6`. The generator makes exactly four transformations: each OAI `$dynamicRef: "#meta"` that targets a Schema Object becomes a static `$ref: "#/$defs/schema"`. The adapted schema JSON SHA-256 is `f301b37b6ec27b0ada35082b8a5868967bc1e68dcc330ff745470a4c468df56e`. OAI uses those dynamic references to allow a separate dialect schema to override Schema Object validation. This task applies only the published structural schema, without a dialect override. Pinning them to OAI's own `$defs/schema` placeholder therefore preserves its structural checks while avoiding Ajv 8.20.0's incompatible dynamic-reference resolution for this source.

The source schema is intentionally **without Schema Object validation**. It checks that Schema Object positions contain an object or boolean, but does not prove that every embedded JSON Schema keyword or reference is valid. Ajv's `format` assertions are disabled in this standalone structural build. OAI also notes that its published schemas do not establish full conformance with every prose rule of the OpenAPI Specification. A passing structural lint is one part of this task's verification; `verify-auth-user-friend.ps1` separately checks the canonical Auth/User/Friend semantics, error bindings, and golden fixtures. The checker does not claim full OpenAPI conformance by itself.

To reproduce the generated validator, install the pinned Ajv version in a disposable location and run `node contracts/http/build-openapi-3.1-validator.js <path-to-ajv-package>`. The generated file has no runtime package dependencies. `check-openapi-3.1.js` reads JSON from standard input and exits nonzero on structural errors. The task verifier executes it on the canonical document and on nine committed invalid-shape regressions, including the three shapes found by independent review.
