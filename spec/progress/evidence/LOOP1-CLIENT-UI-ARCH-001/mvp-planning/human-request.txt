# 十、LOOP1-CLIENT-SEND-001 实现目标

严格按 Frozen Architecture / contracts / SQLite Repository 实现：

```text
用户发送
  ↓
生成不可变 request_id
  ↓
Repository 事务写 SENDING
  ↓
UI/application state 可观察 SENDING
  ↓
WSS message.send
  ↓
durable ACK
  ↓
Repository UPSERT SENT
```

失败：

```text
timeout / offline
  ↓
FAILED
```

重试：

```text
FAILED
 ↓
reuse SAME request_id
 ↓
SENDING
```

必须保证：

- SENT 不倒退；
- ACK / realtime / Sync 可将 SENDING/FAILED 收敛为 SENT；
- retry 绝不生成新的 request_id；
- ACK-before-durable-commit 不得发生；
- 不在 UI 层直接修改 SQLite；
- 不重复实现 SQLite Repository；
- 不修改服务器 contract；
- 不自行创建新的发送 HTTP route；
- 使用现有 WSS canonical contract。
