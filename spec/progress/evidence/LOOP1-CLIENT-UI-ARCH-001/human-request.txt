# 四、视觉系统

## 4.1 Glass 风格

采用：

```
Minimal Glassmorphism
```

原则：

玻璃用于表达层次，不用于装饰。

包含：

- translucent surface；
- subtle border；
- blur；
- layered depth。

禁止：

- 大量发光；
- 霓虹；
- 粒子效果；
- 复杂 3D。
